# Building HFX

These steps rebuild the extension exactly as it's published.

## Requirements

- Node.js 22 or newer (LTS) and npm 10 or newer
- Any operating system (Windows, macOS or Linux)

## Build

```bash
npm ci
npm run build
```

`dist/` then holds the built extension. `main.js`, `serviceWorker.js` and `options-react.js` are bundled and minified by webpack from the TypeScript in `src/` (configuration in `config/`). `options.html` is generated by `config/OptionsBuilderPlugin.ts`. `manifest.json`, `options.css` and the images in `src/assets/` are copied from `src/` unchanged.

The Firefox package's `manifest.json` is `src/manifest.json` as is. The Chrome package's drops the Firefox-only keys (`browser_specific_settings` and `background.scripts`), which `scripts/package.js` removes.

## Release packages

```bash
npm run package
```

This builds, then writes three zips to `releases/`:

- `hfx-<version>-chrome.zip`: for the Chrome Web Store
- `hfx-<version>-firefox.zip`: for Firefox Add-ons
- `hfx-<version>-firefox-source.zip`: this source, for Firefox Add-ons' review

The version comes from `package.json`, and must match `src/manifest.json`.

## Checks

```bash
npm run typecheck
npm test
npm run lint
```
